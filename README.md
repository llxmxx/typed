# typed

instagram web turn `:D` into a 😃 and `>:(` into a blockquote. typed undoes that, so ur messages show up the way u typed.  

emojis you send on purpose are left alone. only the ones instagram converted from text get changed back.  

### install
- download the latest file from releases and unzip it
- open `chrome://extensions` in chrome
- turn on developer mode
- click load unpacked and select the unzipped folder
- open (or reload) instagram

### notes
- typed only changes what you see.
- `:)` and `:-)` both become the same emoji, so typed can't tell which one was typed. it restores the version without the nose for now.
